# AmpireVPN — Telegram-бот для коммерческого VPN

Python 3.12 · aiogram 3 · PostgreSQL · Redis · Remnawave 3.x · ЮKassa · CryptoBot · Docker Compose

Подключение к VPN идёт по ссылке-подписке через приложение **Happ** — бот отвечает за всё остальное:
пробный период, тарифы, оплату, устройства, рефералы, поддержку и администрирование.

## Что умеет

**Пользователь** (единый стиль «премиум», обращение на «вы»):

* **Первый запуск** — приветствие, согласие с документами кнопками-ссылками
  (`Оферта | Конфиденциальность` / `Соглашение | Персональные данные`) и кнопка `Подключить` (пробный период).
  Нажатие «Подключить» фиксируется как акцепт документов (время и версия).
* **Главное меню** — `Моя подписка` · `Приглашения` · `Поддержка`.
* **Тарифы LITE и PREMIUM**, срок на выбор: **1 / 3 / 6 / 12 месяцев** (скидки за срок настраиваются в админке; 12 месяцев = 365 дней).
* **Устройства**: в LITE включено 1, в PREMIUM — 3. На любом тарифе лимит можно увеличить: **+25 ₽ за устройство в месяц**
  (докупка считается пропорционально остатку подписки и затем входит в стоимость продления; кнопка-«степпер» `[−] N [+]`
  с живой ценой; лишнее место можно убрать). Одна точка входа — `Подключить устройство`: есть место — инструкция,
  нет — выбор «увеличить лимит / удалить устройство / перейти на PREMIUM».
* **Поддержка** — раздел с кнопками `Вопросы и ответы` (Telegraph), `Написать в поддержку` и `Документы`.
* Настройка Happ (скачать / добавить подписку — ссылки сами определяют ОС), рефералка, промокоды.

**Оплата**

* **ЮKassa** — карты, СБП, чеки 54-ФЗ / самозанятые, возвраты из админки (под блокировкой — дважды не снимется).
* **CryptoBot** — счёт в рублях, клиент платит любой монетой; вебхук с проверкой подписи + пакетная сверка.
* **Автопродление картой** (ЮKassa; включается в админке): условия и явное согласие показываются **до** привязки карты;
  напоминание за сутки; повторы через 1 и 3 суток с льготным доступом; без двойных списаний (идемпотентность + защита от
  зависшего 3-D Secure).
* **Сверка**: БД → ЮKassa каждую минуту и ЮKassa → БД раз в сутки (плюс кнопка в админке).

**Правила подписок**

* Пробный период — 7 дней PREMIUM с ограничениями (по умолчанию 10 ГБ и 1 устройство; снимаются первой оплатой).
* **LITE → PREMIUM**: доплата за остаток считается по суточным ставкам *текущих* цен —
  `(цена_PREMIUM/дней − цена_LITE/дней) × остаток_дней` — и поэтому не ломается при смене цен, сроков и скидок
  (при ценах 149/249 и остатке 15 дней: 50 ₽). Остаток LITE сохраняется и переходит на PREMIUM.
* PREMIUM → LITE: LITE встаёт в очередь после PREMIUM; лишние устройства отключаются (самые новые).
* Приглашённый подключился и пользуется VPN → пригласивший получает бонус. Антифарм по умолчанию: возраст аккаунта ≥ 24 ч,
  потолок наград, суточный лимит, совпадение устройств.
* Промокоды: скидка (% или ₽) либо бонусные дни; неоплаченная «бронь» освобождает место в лимите через 7 дней.

**Админка** (`/admin`, без консоли) — с **раздельными ролями**: поддержка, биллинг, маркетинг, инфраструктура, администратор;
возвраты, управление админами, удаление пользователей, бэкап и сверка — только владельцам. Статистика, пользователи,
платежи (включая очередь «На проверке»), тарифы, цены и сроки, промокоды, рефералка, рассылки, редактор текстов,
панель VPN, настройки, диагностика, журнал ошибок (общий для всех реплик) и действий.

**Надёжность**

* Ни одного запроса к панели/ЮKassa/Telegram внутри транзакции БД (проверяется тестом на AST).
* `needs_review` для спорных платежей, поиск платежа по `metadata.payment_id`, ретраи с тем же ключом идемпотентности.
* Redis не жёсткая зависимость: fail-open для антиспама и FSM, локальные блокировки, алерт.
* В production бот **не запускается** с небезопасной конфигурацией или при ошибке миграций.
* Мягкая остановка (`stop_grace_period: 45s`), дренаж фоновых задач, деплой по одной реплике.
* Непрерывный архив WAL (PITR) + копия вне сервера + ежемесячный тест восстановления.
* Мониторинг: Prometheus скрейпит **api и worker**, алерты в Telegram, сторож внутри воркера.

## Структура

```
app/
  core/          чистая логика (подписки, цены, сроки, автопродление, лимиты, расчёт платежей) — покрыта тестами
  infra/         блокировки, лимитер, кэш, шина, метрики (с гистограммами), fail-open FSM
  db/            модели SQLAlchemy 2.0
  integrations/  клиенты Remnawave 3.x, ЮKassa v3, CryptoBot (httpx)
  services/      подписки, платежи и провайдеры, промокоды, рефералы, рассылки, статистика, проверка ссылок Happ…
  bot/           aiogram: middlewares, подписи кнопок (labels), экраны (views), хендлеры user/ и admin/
  web/           aiohttp: вебхуки, страницы /dl и /add для Happ, health/metrics
  workers/       фоновые задачи и сторож
  legal.py       реестр документов и ссылки-заглушки · permissions.py — роли админов · startup_checks.py — проверки старта
alembic/         миграции схемы БД (0002 — AmpireVPN)
deploy/          pgBackRest (PITR), Prometheus + алерты, rolling-update.sh
tests/           юнит-тесты (логика, цены, устройства, апгрейд, автопродление, платежи, рассылки, безопасность, миграции, стиль)
scripts/         check_code.py (статическая проверка), ci_smoke.py (БД в CI), lock.sh, decrypt_backup.py
```

## Разработка

```bash
python -m unittest discover -s tests -v     # тесты
python scripts/check_code.py                # статическая проверка: имена, кнопки↔обработчики, тексты, настройки
./scripts/lock.sh                           # requirements.lock с хэшами (один раз, нужен интернет) — Dockerfile подхватит
```

Новые тексты добавляются в `app/texts.py` — сразу становятся редактируемыми из админки. Подписи кнопок — в `app/bot/labels.py`.
Изменили модели — создайте миграцию (`alembic revision --autogenerate -m "…"`); тест `tests/test_migrations.py` следит за
соответствием, а миграции должны быть обратно совместимы со старым кодом (деплой идёт по одной реплике).
